# 갈림길 (청년 커리어 전환 정책 에이전트) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 최소 프로필과 상태 변화(수료·취업·사업자등록)를 받아 청년 정책을 네 개의 축으로 판정하고 상태 전후를 비교하며, 정책 검증 에이전트가 공개 정책을 공식 공고와 대조하고, 상담 에이전트가 가상 인물에게 질문과 행동 카드를 만드는 웹 프로토타입을 11/21까지 배포한다.

**Architecture:** 온통청년 API 스냅샷을 빌드에 포함하고, 판정·상태 전이·질문 순위는 모두 순수 TypeScript 함수로 만든다. 사람이 원문 대조로 확정한 "검증 정책" JSON만 확정 판정에 쓴다. 에이전트는 Next.js API 라우트에서 Claude 도구 호출로 돌고, 도구는 위 순수 함수를 감싼다.

**Tech Stack:** Next.js 15(App Router, TypeScript), Vitest, zod, @anthropic-ai/sdk, tsx(스크립트 실행), Vercel

**Spec:** `docs/2026-11-16-policy-twin-design.md` (7판 최종본). 구현자는 이 계획과 설계 문서를 함께 읽는다. 특히 3장(데이터와 함정), 5장 ③④⑤, 7장, 9장(시연 표와 대조 결과).

## Global Constraints

- 모든 날짜 계산은 `Asia/Seoul` 기준. 서버 시간대와 무관하게 같은 결과.
- 마감 시각이 있으면 그 시각까지, 없으면 종료일 24:00(다음 날 00:00 직전)까지 모집 중.
- 모집 상태는 **접속한 날(판정 기준일)** 로 계산한다. 데이터 기준일과 화면에서 따로 표시.
- 판정 결과 문구는 설계 5장 ④ 표의 문구만 쓴다. "닫힘", "열림", "유리", "선정", "받을 수 있습니다"는 쓰지 않는다.
- **사용자가 입력한 정보와 거기서 나온 정보(상태, 개인별 판정, 질문 답변)는 외부 AI(Claude)에 보내지 않는다.** 외부 AI 호출은 두 곳뿐이다: 정책 검증 에이전트(`/api/verify`, 정책 번호만 받음, 모든 모드), 상담 에이전트(`/api/agent`, 가상 인물 번호만 받음). 실제 사용자의 판정·전이·행동 카드는 코드와 검증 정책 템플릿으로 만든다(설계 7장).
- 판정 등급은 네 가지: 조건상 해당(검증 정책만) / 코드 조건 충족(본문 미검토) / 확인 필요 / 조건상 비해당(원문 정의가 분명할 때만).
- 공고 탐색의 통제는 코드가 한다: 허용 도메인 목록(`go.kr`, 공공기관, 지자체, 온통청년, 그 정책의 주관기관 공식 사이트), 정책당 페이지 열기 최대 6회·검색 최대 3회·60초, robots.txt 준수, 정책 번호별 결과 저장, HTML만 읽음(HWP·PDF는 "첨부 확인 필요").
- 나이는 생년월과 정책별 연령 기준일로 판정한다. 연령 기준일이 없거나, 기준일이 생일 달과 겹쳐 경계에 걸리면 "확인 필요".
- 에이전트 API(`/api/agent`)는 요청 본문으로 `{ personaId: "demo-1"|"demo-2", answer?: { questionKey: string; optionIndex: number } }`만 받는다. 다른 필드가 있으면 400. 가상 인물 프로필은 `lib/agent/personas.ts` 상수에서만 읽는다. 자유 텍스트 입력은 만들지 않는다.
- `EXTERNAL_AI_ENABLED`가 `"true"`가 아니면 외부 AI를 부르지 않고 사전 생성 문장으로 동작한다.
- 프로필은 브라우저 localStorage에만 저장. 서버는 요청 처리 후 저장·로그하지 않는다.
- API 키(온통청년, Anthropic)는 서버 환경변수로만. `.env*`는 저장소에서 제외.
- 모델: 에이전트 `claude-sonnet-5-5`, 개발 단계 조건 추출 `claude-haiku-5-5`.
- 모든 화면에 설계 5장 ⑥의 고지 4개를 그대로: 데이터·판정 기준일, "신규 정책과 공고 변경 사항은 데이터 기준일 이후 반영되지 않았습니다", "'조건상 해당'은 … 선정을 보장하지 않습니다", "AI가 생성한 설명입니다 / 최종 자격은 담당 기관에서 확인하세요". 현재 모드(가상 인물 / 내 정보)도 표시.
- 같은 사업 묶기는 과거 이력 화면 표시에만. 판정은 정책 번호별 개별 공고 조건으로만.
- 확정 판정("조건상 해당")은 `verification_status: "human_verified"`인 검증 정책에만.
- 비로그인 접속, 12/7까지 동작. 에이전트 한도 초과 시 판정·비교 화면은 계속 동작.

## Review Focus

- 수료 예정일이 이미 지났는데 사용자가 완료로 바꾸지 않은 경우: 수료로 간주하지 않고, 카드에 "수료하셨다면 상태를 바꿔 주세요"가 뜬다. (Task 5에 테스트)
- 온통청년 API가 수집 중 실패: 기존 스냅샷 파일이 그대로 남는다. (Task 2에 테스트)
- 에이전트 응답에 금지 표현("유리합니다", "선정") 또는 도구 결과에 없는 정책 번호가 섞임: 응답을 버리고 템플릿 카드로 대체. (Task 8에 테스트)
- 같은 상태 변경 버튼을 연속으로 여러 번 누름: 결과가 한 번 누른 것과 같고 프로필은 변하지 않는다. (Task 6에 테스트)
- 한 사람에게 200건 안팎이 해당: 기본 목록은 "상태 변화로 바뀌는 것 + 30일 내 마감 + 검증 정책"만 보이고 나머지는 접힌다. (Task 9에 테스트)
